# CodeAlpha Matrix Operations

A matrix operations program developed using C programming as part of the CodeAlpha C Programming Internship.

## Project Overview

This project is a C program that performs three basic matrix operations: matrix addition, matrix multiplication, and matrix transpose.

## Features

* Matrix Addition
* Matrix Multiplication
* Matrix Transpose
* Checks whether matrix addition is possible
* Checks whether matrix multiplication is possible
* User-friendly input and output

## Concepts Used

* C Programming
* 2D Arrays
* Functions
* Nested `for` loops
* `scanf()` for taking user input
* `printf()` for displaying output
* Conditional statements
* Matrix operations

## How the Program Works

1. The user enters the rows and columns of Matrix A.
2. The user enters the elements of Matrix A.
3. The user enters the rows and columns of Matrix B.
4. The user enters the elements of Matrix B.
5. The program performs matrix addition if both matrices have the same dimensions.
6. The program performs matrix multiplication if the columns of Matrix A match the rows of Matrix B.
7. The program displays the transpose of Matrix A.
